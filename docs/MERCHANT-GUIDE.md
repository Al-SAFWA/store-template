# دليل التاجر — Guide du commerçant

> نسخة عربية أولاً، ثم ملخص بالفرنسية. يُسلَّم هذا الملف للتاجر مع روابط متجره. لا يحتوي أي كلمة سر.

## 1. روابطك
| ماذا | أين |
|---|---|
| المتجر (للزبائن) | `https://<اسم-متجرك>.pages.dev/` |
| لوحة التحكم (لك ولموظفيك) | `https://<اسم-متجرك>.pages.dev/dashboard.html` |
| الدخول | بريدك الإلكتروني + كلمة المرور التي أُعطيت لك. غيّرها من **ملفي الشخصي** أول مرة. |

رقم إصدار النظام يظهر أسفل القائمة الجانبية في اللوحة (`v1.10.0` مثلاً). اذكره عند طلب الدعم.

## 2. الطلبات اليومية
1. يصل الطلب من المتجر إلى **الطلبات** خلال نصف دقيقة، مع صوت تنبيه إن كانت اللوحة مفتوحة، ويصلك أيضاً على واتساب برسالة فيها المنتج والكمية والعنوان.
2. افتح الطلب → غيّر **الحالة**: جديد ← مؤكد ← قيد التوصيل ← تم التسليم (أو ملغى).
3. زر **فاتورة** يطبع فاتورة، وزر **ملصق شحن** يطبع ورقة فيها اسم الزبون وهاتفه وعنوانه.
4. المخزون يُخصم تلقائياً لحظة الطلب. إن أُلغي الطلب أعد الكمية يدوياً من صفحة المنتج.

## 3. المنتجات
- **منتج جديد**: الاسم بالعربية والفرنسية، السعر، المخزون، صورة واحدة على الأقل، الفئة.
- **الخيارات** (لون/سعة): لكل خيار مخزونه وسعره الإضافي. الرقم الظاهر في القائمة هو مجموع مخزون الخيارات.
- **نشط/مخفي**: المفتاح الدائري في القائمة يُظهر المنتج للزبائن أو يخفيه فوراً دون حذفه.
- **تعديل أسعار جماعي**: زر أعلى القائمة لرفع/خفض الأسعار بنسبة لفئة كاملة.
- الصور: استعمل صوراً مربعة بعرض 1000 بكسل تقريباً، أقل من 300 كيلوبايت.

## 4. المحتوى والمظهر
- **الصفحة الرئيسية**: الشرائح العلوية (صورة + عنوان + زر)، الفئات، الأقسام. الصور تُرفع من حاسوبك أو برابط.
- **نصوص المتجر**: شريط الإعلان، سياسة الإرجاع، الضمان، طرق الدفع، المدن ورسوم التوصيل.
- **المظهر**: الألوان والشعار والوضع الليلي.
- كل تغيير يبقى **مسودة** حتى تضغط **نشر** أعلى الصفحة. المتجر يتحدث عند الزبائن خلال ثوانٍ، دون أن يفقدوا سلّتهم.

## 5. الكوبونات والعروض
- **التسويق → الكوبونات**: رمز، نسبة أو مبلغ، حد أدنى، تاريخ انتهاء، عدد مرات الاستعمال.
- خصم طريقة الدفع (مثلاً 2% للدفع ببنكيلي) يُضبط من **طرق الدفع**.

## 6. الموظفون
- **الفريق**: أضف موظفاً ببريده؛ الدور **staff** يدير الطلبات والمنتجات لكنه لا يغيّر الإعدادات ولا يضيف موظفين. **owner** لك وحدك.
- كل عملية (حفظ، حذف، نشر) مسجلة في **سجل التدقيق** باسم من قام بها.

## 7. النسخ الاحتياطي
- يُؤخذ تلقائياً كل أسبوع ويُحفظ في مستودع متجرك على GitHub (مجلد `backups/`).
- يدوياً: **الإعدادات → النسخ الاحتياطي → تصدير** يعطيك ملفاً واحداً فيه كل شيء؛ **استيراد** يعيده، مع زر تراجع.

## 8. إن حدثت مشكلة
| العرض | السبب الغالب | الحل |
|---|---|---|
| اللوحة تعرض أرقاماً قديمة أو شريطاً أصفر "تعذر الاتصال بقاعدة البيانات" | مانع إعلانات أو **Brave Shields** يحجب الاتصال | اضغط أيقونة الدرع/الأسد بجانب العنوان → أطفئه لهذا الموقع → أعد التحميل |
| شريط أصفر "أنت داخل بحساب محلي" | دخلت بحساب تجريبي من المتصفح لا بحساب Supabase | سجّل الخروج وادخل ببريدك |
| الزبون يقول إن الطلب لم يُرسل | هاتفه بلا إنترنت لحظة الضغط، أو رقم واتساب المتجر غير مضبوط | تحقق من **الإعدادات → واتساب**، واطلب منه إعادة المحاولة |
| المتجر لا يفتح | نشر جارٍ (دقيقتان) أو انقطاع في Cloudflare | انتظر 3 دقائق ثم أعد المحاولة |
| نسيت كلمة المرور | — | صفحة الدخول → "نسيت كلمة المرور" (تصل رسالة إلى بريدك) |

## 9. ما لا تفعله
- لا تعطِ بيانات دخول **owner** لأحد؛ أنشئ حساب staff.
- لا تعدّل الملفات على GitHub يدوياً؛ التحديثات تصل تلقائياً كل ليلة ويُفتح لك تنبيه إن احتاج التحديث خطوة منك.
- لا تحذف مشروع Supabase: هو قاعدة بياناتك (الطلبات، المنتجات، الزبائن).

# Résumé en français
- **Boutique** : `https://<nom>.pages.dev/` · **Tableau de bord** : `/dashboard.html` (e-mail + mot de passe ; changez-le dans *Mon profil*). La version du système est affichée en bas du menu.
- **Commandes** : arrivent dans *Commandes* en moins de 30 s (+ WhatsApp). Changez le statut, imprimez *Facture* ou *Étiquette*. Le stock est décrémenté automatiquement.
- **Produits** : titre AR/FR, prix, stock, photo carrée (~1000 px, < 300 Ko). Les variantes ont chacune leur stock ; la liste affiche le total. L’interrupteur *actif/masqué* cache un produit sans le supprimer.
- **Contenu** : tout reste en brouillon jusqu’à **Publier** ; la boutique se met à jour en quelques secondes.
- **Équipe** : rôle *staff* = commandes et produits ; *owner* = vous seul. Tout est journalisé.
- **Sauvegarde** : automatique chaque semaine sur GitHub ; export/import manuel dans *Paramètres*.
- **Problèmes** : bandeau jaune « connexion impossible » → désactivez le bloqueur de pubs / Brave Shields pour ce site ; bandeau « compte local » → reconnectez-vous avec l’e-mail Supabase ; boutique indisponible → attendez 3 min (déploiement).
- **À ne pas faire** : partager le compte owner, modifier les fichiers sur GitHub, supprimer le projet Supabase.
